# IFComunidade — Back-end

API do IFComunidade, uma plataforma de ouvidoria, informação e comunicação do IFC Campus Araquari.

O projeto busca aproximar a comunidade acadêmica, oferecendo um espaço para registrar ocorrências e compartilhar informações do campus.

## Funcionalidades

- Cadastro e autenticação de usuários.
- Registro e acompanhamento de ocorrências.
- Gestão de postagens para o mural.
- Organização de categorias, cursos e trâmites.
- Upload de arquivos.

## Tecnologias

Python, Django, Django REST Framework e autenticação JWT.
